## Overview

The dashboard no longer has an Orbital Surveillance map layer (layer key `satellites`). Live satellite tracking was removed together with the 3D globe, and the imagery-footprint layer that replaced it was removed at the owner's request. A saved layer setting or a `?layers=` link that still names `satellites` loads without it.

To see when a satellite passed over a specific place, use [Orbital Watch](/orbital-watch), which draws pass ground tracks on the flat map.

---

## Server-side surfaces that remain

| Surface | Endpoint | Notes |
|---|---|---|
| SAR / optical scene search | `GET /api/imagery/v1/search-imagery` | STAC-backed Sentinel search by `bbox`, `datetime`, `source`, and `limit`, cached per canonical provider request, including the precise bounding box. No dashboard consumer. |
| Satellite TLE mirror | `GET /api/intelligence/v1/list-satellites` | Generated IntelligenceService RPC reading `intelligence:satellites:tle:v1`. Read by the terminal dashboard. |

| Key | TTL | Writer | Shape |
|-----|-----|--------|-------|
| `intelligence:satellites:tle:v1` | 4h | Relay (2h cycle) | `{ satellites: SatelliteTLE[], fetchedAt: number }` |
| `seed-meta:intelligence:satellites` | 7d | Relay | `{ fetchedAt: number, recordCount: number }` |
