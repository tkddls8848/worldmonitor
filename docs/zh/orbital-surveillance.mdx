## 概述

仪表盘不再提供轨道监视地图图层（图层键 `satellites`）。实时卫星追踪已随 3D 地球仪一同移除，之后替代它的影像覆盖范围图层也应所有者要求移除。仍包含 `satellites` 的已保存图层设置或 `?layers=` 链接会忽略该图层并正常加载。

如需查看卫星何时经过某个地点，请使用[轨道观察](/zh/orbital-watch)，它会在平面地图上绘制过境地面轨迹。

---

## 保留的服务端接口

| 接口 | 端点 | 说明 |
|---|---|---|
| SAR / 光学影像检索 | `GET /api/imagery/v1/search-imagery` | 基于 STAC 的 Sentinel 检索，参数为 `bbox`、`datetime`、`source` 和 `limit`，按规范化请求（含精确边界框）缓存。没有仪表盘使用方。 |
| 卫星 TLE 镜像 | `GET /api/intelligence/v1/list-satellites` | 生成的 IntelligenceService RPC，读取 `intelligence:satellites:tle:v1`。由终端仪表盘读取。 |

| 键 | TTL | 写入方 | 结构 |
|-----|-----|--------|-------|
| `intelligence:satellites:tle:v1` | 4h | Relay（2h 周期） | `{ satellites: SatelliteTLE[], fetchedAt: number }` |
| `seed-meta:intelligence:satellites` | 7d | Relay | `{ fetchedAt: number, recordCount: number }` |
