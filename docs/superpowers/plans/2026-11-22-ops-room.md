# Ops Room (Battle Board) Implementation Plan

> **For agentic workers:** each task below is one worker. Read the header, Global Constraints, Rulings and Interfaces, then YOUR task only.

**Goal:** the world first screen reads as a battle operations room: a global threat level, operations counters, a multi-timezone clock strip, a live event log, and tactical map marks (hotspots, target brackets, grid), in a new dark "작전 상황실" theme. The light theme stays the printed-atlas design.

## Global Constraints

- Import direction `types -> config -> services -> components -> app` (`node scripts/lint-boundaries.mjs`).
- Already on `main`: `src/types/world-overview.ts` (`ThreatLevel`, `OpsCounters`, `OpsMetrics`, `OpsEvent`, `OpsEventSeverity`, `MapHotspot`, `WorldMapView.hotspots`), `pickHotspots()` in `src/services/world-overview-view.ts`.
- No new npm dependencies. Never hand-edit `src/generated/`. No raw `innerHTML` (use `setTrustedHtml(trustedHtml(...))` from `src/utils/dom-utils.ts`; `node scripts/enforce-safe-html.mjs` must pass). Korean UI copy. Inline SVG icons, no emoji.
- Performance: the first screen must not get slower (cold LCP today ≈ 0.08 s). Continuous animation only via CSS transform/opacity or a deck layer prop driven at most every 100 ms; everything static under `prefers-reduced-motion: reduce`. No timers when the world view is hidden.
- Components expose `.element` and `destroy()`; they style with class names prefixed `wfs-ops-` and read colours from CSS custom properties (`--ops-*`), with sensible fallbacks, so the visual spec can restyle them without code changes.

## Rulings

1. Threat score (0–100, one decimal) = min(100, 8·wars + 2·highConflicts + 1·worsening + 0.2·breaking24h + 0.02·sanctionPairs + 0.5·activeOutages); calibrated so the late-2026 baseline (4 wars, ~17 high) reads level 2. Level: ≥80 → 1, ≥60 → 2, ≥40 → 3, ≥20 → 4, else 5. Labels: 1 "최고 위기", 2 "고위험", 3 "경계", 4 "주의", 5 "평시". Active outages are open events or events ended within the last 6 hours.
2. Counters use the whole snapshot (not only the 30 drawn lines). `breaking24h` counts alerts whose time is within 24 h of `now`.
3. Event log keeps the newest 50 events, newest first. Sources: breaking alerts (`wm:breaking-news`, severity from the alert's level), today's AI relations (kind tension/sanction → high, support/alliance → medium), country issues (medium), and active/recent IODA outages (severity from the outage). Event ids are stable so re-loading the snapshot does not duplicate.
4. Clocks: UTC, 서울 (Asia/Seoul), 워싱턴 (America/New_York), 브뤼셀 (Europe/Brussels), 베이징 (Asia/Shanghai), 모스크바 (Europe/Moscow); 24 h `HH:MM`; one shared 1 s ticker paused while `document.hidden` or the world view is hidden.
5. Map: hotspot = ring around `MapHotspot.coord`, radius by level (4 → 22 px, 3 → 16 px), pulsing opacity 0.25↔0.7 over 2.4 s unless reduced motion; target brackets = four corner marks around the selected country's centroid (28 px box); tactical grid = graticule every 15° (light: hidden; dark: shown).

**Task 3 – tactical map layers** (`src/components/map/world-overview-layers.ts`, `src/config/world-overview-palette.ts`):
